# E-colle scraper Docs

This project sends __[ntfy](https://ntfy.sh)__ notifications with your next "colles", read from a CSV export of your ecolle agenda.

Since version 2.0.0 the colles come from a CSV file instead of being scraped from an ecolle instance. Scraping is only kept as an optional fallback.
